Froxel for Linux

A voxel editor with a path tracer and an MCP server. Source and other systems.

Debian, Ubuntu, Mint, Pop!_OS (apt)

sudo curl -fsSLo /usr/share/keyrings/froxel.gpg @BASE@/froxel.gpg
echo "deb [signed-by=/usr/share/keyrings/froxel.gpg] @BASE@ stable main" \
  | sudo tee /etc/apt/sources.list.d/froxel.list
sudo apt update && sudo apt install froxel

Updates come with sudo apt upgrade. Debian 10+ and Ubuntu 20.04+, on x86_64, ARM64, and RISC-V.

Fedora, RHEL, CentOS Stream, Rocky, Alma (dnf)

sudo dnf copr enable @COPR@
sudo dnf install froxel

copr comes with dnf-plugins-core. Fedora, and RHEL 8+ and its rebuilds, on x86_64 and ARM64.

Arch, Manjaro (AUR)

yay -S froxel-bin

Any distribution

flatpak install flathub com.lonje.Froxel
sudo snap install froxel

Download a .deb, .rpm, or .tar.gz from the latest release.
